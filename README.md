# CSEE E6863 Fall 2026 Project

Course project for CSEE E6863: Formal Verification of Hardware and Software Systems at Columbia University.

## Direction

We will study LLM-assisted software verification using GPT or Claude to work with the Lean 4 and Dafny command-line tools, with Pyright as a static-analysis baseline. We will compare the results, effort, usability, and limitations of these approaches. The implementation approach will be refined through initial experiments.
